# Dokumentasi Day 1 Proyek Workshop

## 1. Rangkuman Materi Workshop

### A. Prompt Engineering

Prompt Engineering adalah cara merancang instruksi agar AI dapat memberikan jawaban yang tepat, relevan, dan sesuai kebutuhan.

Prompt merupakan instruksi atau masukan yang diberikan kepada model AI untuk mendapatkan hasil tertentu.

Dalam workshop, dipelajari empat struktur prompt yang baik:

1. **Role:** Menentukan peran AI.
2. **Task:** Menjelaskan tugas yang harus dilakukan.
3. **Context:** Memberikan informasi atau latar belakang.
4. **Format:** Menentukan bentuk hasil yang diinginkan.

Dengan memberikan instruksi dan konteks yang jelas, AI dapat menghasilkan jawaban yang lebih sesuai dengan kebutuhan pengguna.

### B. Git dan GitHub

Git adalah Version Control System yang digunakan untuk melacak dan mengelola perubahan pada file atau proyek.

GitHub adalah platform berbasis web yang digunakan untuk menyimpan repository Git secara online dan mendukung kolaborasi.

Beberapa istilah yang dipelajari:

- **Repository:** Tempat penyimpanan file proyek.
- **Commit:** Catatan perubahan yang disimpan dalam Git.
- **Branch:** Cabang pengembangan proyek.
- **Pull Request:** Mekanisme untuk mengusulkan perubahan agar dapat ditinjau dan digabungkan.
- **Version Control:** Sistem untuk melacak perubahan proyek.

Tiga bagian dalam Git Workflow:

1. Working Directory: Tempat mengerjakan dan mengubah file.
2. Staging Area: Tempat mempersiapkan perubahan sebelum commit.
3. Git Directory: Tempat Git menyimpan data dan riwayat proyek.

### C. Perintah Dasar Git

Beberapa perintah Git yang dipelajari selama workshop:

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin URL_REPOSITORY
git push origin main
git pull origin main
git clone URL_REPOSITORY
```

## 2. Poin Penting dan Pengetahuan Baru

1. Memahami cara membuat prompt AI yang lebih spesifik.
2. Mengetahui struktur Role, Task, Context, dan Format.
3. Memahami perbedaan Git dan GitHub.
4. Mengetahui fungsi repository dalam pengembangan proyek.
5. Memahami fungsi commit untuk menyimpan perubahan.
6. Mempelajari cara mengunggah proyek ke GitHub.
7. Mengetahui bahwa GitHub dapat membantu penyimpanan dan kolaborasi proyek.
