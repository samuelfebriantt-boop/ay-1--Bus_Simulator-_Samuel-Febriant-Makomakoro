2. Menyimpan pengetahuan baru yang diperoleh selama kegiatan.
3. Memahami penggunaan Git dan GitHub untuk mengelola proyek.

## Materi Workshop

Pada Day 1 Proyek Workshop, terdapat dua materi utama yang dipelajari:

1. **Prompt Engineering:** Mempelajari cara membuat instruksi yang jelas dan spesifik agar AI memberikan hasil sesuai kebutuhan.

Dokumentasi lengkap mengenai rangkuman materi, pengetahuan baru, dan pendapat pribadi tersedia pada folder `Dokumentasi`.
